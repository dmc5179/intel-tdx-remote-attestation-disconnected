# Operational Scripts

Scripts for managing Intel TDX attestation infrastructure.

## fetch-platform-collateral.sh

Automates the platform collateral workflow: collecting CSV files from TDX
hosts, fetching collateral from Intel PCS, and inserting it into PCCS.

### Quick start (single-server testing)

```bash
# All-in-one — collect, fetch from Intel PCS, insert into PCCS
./fetch-platform-collateral.sh full ./csv-dir/ https://127.0.0.1:8081 \
  --api-key YOUR_INTEL_PCS_API_KEY \
  --admin-token YOUR_PCCS_ADMIN_TOKEN
```

### Step-by-step (air-gapped deployment)

**On the connected side:**

```bash
# 1. Merge CSV files from TDX hosts
./fetch-platform-collateral.sh collect ./csv-dir/

# 2. Fetch collateral from Intel PCS
export INTEL_PCS_API_KEY=your-key
./fetch-platform-collateral.sh fetch
```

Transfer `collateral-output/platform_collaterals.json` to the disconnected
enclave via sneakernet.

**On the disconnected side:**

```bash
# 3. Insert into PCCS
export PCCS_ADMIN_TOKEN=your-admin-token
./fetch-platform-collateral.sh insert https://pccs-host:8081
```

### Prerequisites

- `podman` installed
- PCS Client Tool container image (`quay.io/danclark/intel-tdx/pcs-client-tool:latest`)
- PCCS Admin Tool container image (`quay.io/danclark/intel-tdx/pccs-admin-tool:latest`)
- Intel PCS API subscription key (free at
  [api.portal.trustedservices.intel.com](https://api.portal.trustedservices.intel.com/manage-subscriptions))
- CSV files from each TDX host (generated by `PCKIDRetrievalTool`)
